# 혼합 문제유형 + 참가자 공개설계

날짜: 2026-09-24
관련: `docs/superpowers/specs/2026-09-24-ai-arena-design.md` (§3 데이터 모델 확장)
상태: 사용자 요청 구현 (Q1 혼합유형·난이도 / Q2 공개설정·랜덤매칭)

## 1. 문제 유형 3종

- `choice` (4지선다, 기본): `options` 4개, `answerIndex` 0-3. 종류가 없는 옛 문제는 전부 choice로 본다.
- `ox` (O/X): `options`는 항상 `["O", "X"]`, `answerIndex` 0 또는 1. AI가 `o/x/○/×` 변형을 내면 `O/X`로 정규화한다.
- `short` (단답형 주관식): `options` 없음, `answerText`에 정답(30자 이내). 채점은 띄어쓰기·대소문자 무시 완전일치.

## 2. 출제 비율 (기본값, 문항수 N)

- 4지선다 `N - ox - short`개, OX와 단답형은 각각 `max(2, round(N × 0.15))`개.
- 예: 20문제 → 14/3/3, 10문제 → 6/2/2. 교사가 에디터에서 유형을 바꾸·지우면 최종 비율은 달라질 수 있다.

## 3. 난이도 정책 (프롬프트에 강제)

- 학년 어휘·문장 길이 준수 (저학년은 짧은 문장, 쉬운 말).
- 고른 성취기준의 동사 수준에 맞춤: 알기(이해 확인) → 기준 문장 그대로 묻지 않고 예시·상황으로 묻기, 적용(활용) → 실생활 문장제·사례 판단.
- 너무 쉬운 문제(상식선)와 너무 어려운 문제(상위 학년 개념) 금지.
- 오답 선택지는 학생들이 흔히 하는 실수(오개념) 기반 4지선다, OX는 단정적 표현 함정 1개 이상.
- 해설 1줄은 "왜 정답인지" 이유를 반드시 포함.

## 4. 단답형 채점 규칙

- `normalize`: 앞뒤 공백 제거 → 모든 공백 제거 → 영문 소문자화. 양쪽을 같은 방식으로 바꿔서 비교.
- 빈 답안은 무조건 오답. 숫자·단어 모두 동일 규칙.
- 라운드 종료 후 정답(`answerText`)을 정답자에게만 보여주지 않고 양쪽 결과 화면의 복습용으로 둔다(후속 과제).

## 5. 아레나 공개 on/off (기존 유지)

- `locked == true` = 학생 목록에서 숨김. 선생님 아레나 탭의 잠금 버튼 그대로 (문구: 잠금/잠금 해제).

## 6. 참가자 공개 설정 (신규)

- `arenas.showPlayers` (없으면 비공개로 간주 — 초등 개인정보 안전 기본값).
- 공개: 대기·준비·대결 내내 상대 이름·아바타 표시.
- 비공개: 끝날 때까지 `???` 표시, 결과 화면에서만 상대 공개.
- 방 생성 시점 값을 `rooms.showPlayers`에 복사해서 고정 — 게임 중 선생님이 설정을 바꿔도 진행 중인 방은 안 바뀐다.

## 7. 랜덤 매칭

- 대기 중인 방이 여러 개면 그중 하나를 무작위로 골라 입장 (`pickRandom`, `Math.random` 기반).
- 1명 방·내가 만든 방 제외 등 기존 조건은 그대로.
