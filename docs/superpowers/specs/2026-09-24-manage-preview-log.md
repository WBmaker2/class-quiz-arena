# 학급 관리·미리보기 수정 기록

날짜: 2026-09-24
요청: 학급 수정·선택 정리·학생 미리보기 (과정 기록용)

## 한 일

1. 학급 이름 수정: 학생 탭 상단에 학급 관리 블록 (이름 입력 + 저장). `renameClassroom`은 빈 이름 거부, 선생님 본인 학급만 규칙 통과.
2. 같은 화면에서 새 학급 만들기: `ClassCreate`에 돌아가기 버튼 추가 후 재사용. 만들면 새 학급으로 바로 이동.
3. 선택 화면에서 만들기 버튼 숨김: `ClassSelect`는 목록 전용으로. (새 학급은 2번 화면에서 만듦)
4. 학생 화면 미리보기: 워크스페이스 상단 버튼 → `?preview=학급ID` 새 탭. 로그인 후 학생홈·대결 그대로 사용(참여 가능). 진행 중인 방 설정(참가자 공개·읽어주기)은 방 생성 시점 값이라 미리보기와 무관하게 유지.
5. 보안 점검: Gemini 키 값은 레포·히스토리에 없음 (환경변수 이름만 참조). `.env.production`·secret 파일 미커밋·무시済. Firebase 웹 키는 코드에 없음(템플릿만). 마스터 이메일·금칙어 목록은 식별자 수준 공개로 판단 (후속: 금칙어 서버 이전 검토).
