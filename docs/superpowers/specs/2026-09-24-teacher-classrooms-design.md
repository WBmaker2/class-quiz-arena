# 선생님 학급 선택 설계

날짜: 2026-09-24
문제: 선생님은 로그인할 때마다 새 학급 만들기 화면만 나왔다.

## 규칙 (학급 수 기준)

- 0개: 기존 만들기 화면 그대로 ("새 학급을 만들어볼까요?", 첨부 이미지와 동일).
- 1개: 자동으로 그 학급에 접속 (추가 클릭 없음).
- 2개 이상: 학급 목록에서 선택 (이름 + 초대 코드 표시) + 새 학급 만들기 버튼.

## 구현

- `useTeacherClassrooms(uid)`: `classrooms where teacherId==uid` 실시간 구독 → `{ classrooms: [{id, name, inviteCode}], loading }`. 조회 실패하면 빈 목록으로 취급(만들기 화면으로 유도).
- `useClassroom`에 `select(id)` 추가 (hook 상태에 학급 설정). `create()`는 성공 시 학급 ID를 반환, 실패 시 null.
- `ClassSelect` (신규 화면): "어느 학급으로 들어갈까요?" + 목록 버튼 + 새 학급 만들기 버튼.
- `TeacherGate` (App 내부): 위 0/1/N 분기. 학급 1개면 effect 1회로 자동 입장. 테스트 환경(`MODE==='test'`)에서는 조회 없이 만들기 화면 (기존 App 테스트 유지).
- 입장 확정 시 내 `users` 문서의 `classroomId`도 함께 저장 (리더보드·명단 기준 일치).
- 규칙 변경 없음 (학급 읽기는 로그인 사용자 허용済).
